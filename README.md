## Sobre Mí

Soy Ingeniero en Ciencias de la Computación graduado de la Universidad Politécnica Salesiana. Mi enfoque profesional combina el rigor de las ciencias de la computación con la ingeniería de software aplicada a problemas del mundo real:

* **Sistemas Empresariales Críticos:** Experiencia comprobada diseñando arquitecturas desacopladas (NestJS, Ionic/Angular) capaces de interactuar de forma segura con motores de datos legacy de gran escala como **IBM DB2 / AS400** en el sector eléctrico nacional (Centrosur).
* **Computación de Alto Rendimiento y Visión Artificial:** Dominio de **C++17**, **OpenCV**, programación de kernels paralelos en **CUDA / PyCUDA** y modelos de Deep Learning (**PyTorch**), logrando aceleraciones cuantificables (hasta 12x speedup en GPU) y detección en tiempo real.
* **Inteligencia Artificial Agéntica y Generativa:** Implementación de asistentes autónomos multimodales basados en **Google Gemini** con orquestación estricta de funciones (*Tool Calling*), APIs GraphQL y síntesis de voz neural.
* **Sistemas Concurrentes y Distribuidos:** Modelado de arquitecturas paralelas bajo el paradigma SPMD utilizando **MPI** (*mpi4py*), evaluando escalabilidad y eficiencia bajo la Ley de Amdahl.

## Currículum Vitae (Formatos LaTeX)

Este repositorio dispone de dos versiones del currículum vitae en código fuente LaTeX, diseñadas para distintos propósitos dentro del proceso de selección profesional:

### 1. Versión Estilizada (Diseño Visual para Evaluadores y Portafolio)
* **Archivo fuente:** [`CV_David_Uzhca_Software_Engineer_Stilized.tex`](CV_David_Uzhca_Software_Engineer_Stilized.tex)
* **Descripción:** Versión con diseño visual moderno, cabecera azul corporativa (`navy`) de alto impacto, organización en bloques de información y estructura enriquecida para lectura humana. Es el formato ideal para compartir directamente con reclutadores, líderes técnicos o adjuntar en el portafolio personal.
* **Compilación:**
```bash
pdflatex CV_David_Uzhca_Software_Engineer_Stilized.tex
```

### 2. Versión Simplificada (Optimizada para Filtros ATS de 1 Sola Página)
* **Archivo fuente:** [`CV_David_Uzhca_Software_Engineer.tex`](CV_David_Uzhca_Software_Engineer.tex)
* **Descripción:** Versión calibrada estrictamente en 1 página con diseño tipográfico sobrio, libre de cajas o capas de fondo para garantizar una compatibilidad del 100% con los sistemas automáticos de rastreo de candidatos (Applicant Tracking Systems - ATS como Workday, Taleo o Greenhouse). Es el formato recomendado para postulaciones en portales de empleo automatizados.
* **Compilación:**
